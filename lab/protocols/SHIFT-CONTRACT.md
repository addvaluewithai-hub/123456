# Shift Contract

A shift is one complete scheduled research round and must be independently auditable.

## Required run header

Record: reserved R-number, operational shift ID, task ID, branch ID, role, Cairo timestamp, state before/after, mission, success/falsification test, artifacts read, external research performed, code/configs executed, artifacts changed, and evidence state.

## Execution contract

1. **Reconstruct truth.** Resolve contradictions before adding work.
2. **Name one bottleneck.** One sentence, measurable if possible.
3. **State hypothesis and counter-hypothesis.** What mechanism could work, and what likely closes/kills it?
4. **Build the ledger.** Source, power stroke, reset, hidden costs, losses, state restoration, theoretical ceiling.
5. **Do substantive work.** Calculation, code, targeted evidence search, experiment design, or analysis—whichever can change the decision.
6. **Use a fair baseline.** Same source, constraints, volume/mass/stroke where relevant.
7. **Try one serious mutation before killing** when the failure is engineering/local rather than fundamental.
8. **Adversarial review.** Ask what assumption dominates, what a skeptical expert would challenge, and whether the result depends on unmeasured/fitted quantities.
9. **Classify evidence.** Analytical / numerical / published experimental / our bench measured / independently replicated.
10. **Gate the branch.** Use only allowed verdicts and state exactly what would upgrade/downgrade it.
11. **Persist durable artifacts.** Essential knowledge must live outside the run log.
12. **Handoff.** Exact next mission, read-first files, expected output, stop condition.

## Minimum quantitative output

A research run should normally contain at least one numerical estimate, bound, dimensionless comparison, uncertainty interval, or explicit integral/balance. If that is impossible, explain why the run still materially reduced uncertainty.

## Stop conditions

Stop rather than fabricate when a decisive parameter requires unavailable hardware measurement, a primary source is inaccessible and material, authoritative evidence conflicts without a way to resolve it, or numerical tooling cannot be validated. A precise blocker is productive; invented certainty is not.
