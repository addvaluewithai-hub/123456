# Energy Accounting Protocol

Every architecture must answer the following before promotion.

## Required ledger

- real external source/reservoir/gradient;
- state variables that change during the power stroke;
- useful exported work/electricity;
- every control/reset coordinate;
- restoration path to the initial cyclic state;
- dissipative losses;
- material depletion or storage change;
- reversible/theoretical ceiling;
- steady-cycle balance.

For mechanical coordinates use the complete-cycle work, e.g. `∮F·dx` and/or `∮τ dθ`. For thermodynamic systems close heat/work/mass flows and state return. For fields use energy/co-energy consistently and cross-check numerical force integration when an anomaly matters.

## External-control gain

A useful engineering metric may be `G = useful exported energy / explicit control-reset energy`, but `G>1` is interesting only when the source of the difference is a real identified reservoir/gradient. A trigger can control a larger flow; it does not create it.

## Magnets

Fixed permanent magnets/passive reversible magnetic material may reshape forces and barriers but are not credited as a recurring source when all states return. Moving/switching shunts or control magnets introduce control coordinates whose full-cycle work must be counted. Permanent-magnet depletion is fuel unless restored.

## Fair comparison

Compare the proposed trick with a strong direct converter using the same real source and comparable resource constraints. Large output under prescribed motion/temperature/pressure does not prove high source-to-output efficiency unless source work/heat is measured or bounded.
