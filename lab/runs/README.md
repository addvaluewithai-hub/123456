# Run Logs

Append-only research shift logs live under `lab/runs/YYYY-MM-DD/`.

Recommended filename: `R074-shift-YYYYMMDD-HHMM-role.md`.

A run log explains what happened; it is not the only home of important knowledge. Accepted decisions go to `lab/decisions/`, model changes go to code/configs, experiment truth goes to experiment workspaces, and current execution truth goes to STATE/HANDOFF/queue.
